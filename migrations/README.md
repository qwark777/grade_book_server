# Миграции базы данных

Миграции выполняются из корня сервера. Подключение задаётся через `DATABASE_URL` или переменные `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DB`.

```bash
python -m alembic upgrade head
```

Baseline `20260611_0001` вызывает `init_db()` и создаёт недостающие базовые таблицы. Эта команда применяется как для новой базы, так и для базы до внедрения Alembic. Перед изменением рабочей базы сделайте резервную копию.

Создание следующей миграции:

```bash
python -m alembic revision -m "describe change"
# Заполните upgrade() и downgrade(), затем проверьте миграцию на тестовой базе.
python -m alembic upgrade head
```

`alembic stamp` только отмечает ревизию и не выполняет изменения схемы; применяйте его лишь после проверки соответствия схемы выбранной ревизии.

Production-порядок запуска и резервные копии: [руководство эксплуатации](../docs/PRODUCTION_RUNBOOK.md).
